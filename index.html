Paste your class list

Get all your classes from MyRJ at once:
  1. In MyRJ, open any class and go to Roster › Run Roster/Student Reports › Manual Attendance Sheet - By Teacher And Section.
  2. Set Section to All, then choose View/Export › Excel.
  3. Open the downloaded file. Click the letter A above the first column to select the whole column, then press Ctrl+C (Cmd+C on a Mac).
  4. Click in the box below and press Ctrl+V.
  5. Your classes appear as a list. Tick the ones you want and press Set up. Each one gets its own class number, so its students get their own codes.
Or copy from Canvas or MyRJ instead: open one class's Canvas People page, its Canvas Gradebook, or its MyRJ Roster tab. Scroll to the bottom so everyone loads, press Ctrl+A and then Ctrl+C, and paste below. A list of names typed one per line works too.

My class isn't here

Did you set the class up on a different computer? Open Roster Hub on that computer and turn the scores into names there.

Do you have a backup file? Its name starts with raider-roster-hub-backup. It is usually in Downloads or OneDrive.

Do you have a key file? Its name starts with MY-KEY-keep-private.

Not sure whether you have either one? On Windows, open File Explorer, click the search box at the top right, and type MY-KEY, then try roster-hub-backup. On a Mac, press Cmd+Space and type the same words.

None of these? Go to 1 · Set up a class and paste the same class list again, choosing the same class number you used before. The numbers come out the same as long as nobody has joined or left the class since you handed them out. Check a few papers against the list to be sure.

Why numbers instead of names

Many classroom apps ask for a name for every student and keep student work. ZipGrade, for example, keeps a picture of every scanned sheet and has no student-privacy agreement with the school, so real names do not go into it. With Roster Hub, an app only ever sees "Student 307".

What stays where

  • This page runs entirely in your browser. There is no server and no upload. "Remember my classes" keeps the lists in this browser only; "Forget this class" removes one.
  • Other apps get the numbers file: a stand-in name like "Student 307", the number, and the class name, laid out the way that app imports a class. ZipGrade is the first layout; more can be added as we find apps that need one.
  • Your OneDrive keeps the key file and your backup. Those files and this browser are the only places a number turns back into a name.
  • Your other RJ tools on this computer (the Raider Randomizer and the Pod Generator) can use the same class lists, and Roster Hub can use theirs. It all stays in this browser.

Several classes at once

Export the MyRJ attendance sheet with Section set to All and paste column A. Roster Hub lists each class separately, numbers them 1, 2, 3 in order, and names them by block rotation (for example 4W-1W-3W · Biology), since blocks switch every six weeks. IMPACT starts unticked. It never puts all your students into one class.

What students do

Each student gets a slip with their number and uses it wherever the app asks who they are. On a ZipGrade sheet they bubble it in the ID boxes and write it in the name box, and their name goes on the back of the sheet.

Getting scores back to names

Open 2 · Scores back to names and add the results file from the app. If the class is remembered on this computer, Roster Hub picks it from the numbers and lists every score by name. On another computer, restore your backup or open your key file first. If you have neither, set the class up again with the same class number and the same list.

Backups

Remembered classes live in this browser. Clearing its history or site data erases them. Back up all my classes saves one file with every class; Restore from a backup brings them back, on this computer or another one. Your key files also still turn scores back into names.

Rules that keep the numbers right

  • Set up each class once, before you hand out numbers.
  • A student who joins later goes at the bottom. A student who drops keeps their row.
  • The ZipGrade file has 40 seats, so a new student's number is already there.
  • Keep class numbers the same once students have them. A backup keeps the numbers with the classes.
